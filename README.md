# AI 3D Model Orientation Optimizer

## Описание проекта
Этот проект содержит датасет 3D-моделей и их ориентаций для обучения нейросети, которая рекомендует оптимальное положение модели для 3D-печати. Система анализирует геометрию STL-файлов и предлагает наилучшие углы поворота.

## Структура проекта
- `models/` - Исходные STL файлы
- `results/` - Разные ориентации каждой модели (папки `default`, `flat`, `optimal`)
- `json_files/` - JSON файлы с данными по печати
- `models_simple/` - Обученные модели машинного обучения
- `ayto_orient_algo/` - Алгоритм автоматической оптимизации ориентации
  - `auto_orient.py` – основной скрипт: загрузка STL, сбор кандидатов, оценка, поворот
  - `optimize_params_fast.py` – генетический алгоритм для подбора коэффициентов целевой функции
  - `visualize_comparison.py` – сравнение исходной и оптимизированной ориентации
  - `create_test_stl.py` – генерация простых тестовых моделей (куб, пирамида)
- `auto_analyze_full.py` - Скрипт для создания элементов выборки
- `unified_analyzer.py` - Скрипт для создания элементов выборки
- `ai_orientation_predictor.py` - Обучение моделей
- `predict_orientation.py` - Получение рекомендаций
- `stl_vectorizer_fixed.py` - Анализ геометрии STL-файлов
- `update_dataset_from_csv.py` - Создание обучающего датасета

## Формат данных
Каждая ориентация содержит:
- JSON файлы с метаданными
- Анализ геометрии модели
- Параметры печати: расход филамента, время печати, оценка качества

## Как работает программа
Программа анализирует STL-модель, применяет 16 различных ориентаций (повороты по X и Y с шагом 90°), и использует обученную модель для предсказания расхода материала, времени печати и оценки качества. На основе этих предсказаний выбирается оптимальная ориентация с учетом заданных весов параметров.

## Алгоритм автоматической оптимизации ориентации (`ayto_orient_algo`)

Этот модуль реализует детерминированный алгоритм (аналог Tweaker из Cura AutoOrientation), который находит наилучшую ориентацию модели без использования нейросетей или эволюционного поиска в реальном времени. Он работает за доли секунды и не требует обучения.

### Основные этапы

1. **Предобработка mesh** (`_preprocess`)
   - Из STL извлекаются грани, нормали, площади.
   - Удаляются слишком маленькие грани (ускоряет вычисления).

2. **Сбор кандидатов – перспективных ориентаций** (`_collect_candidates`)
   - **`_area_cumulation`** – берёт 12 самых частых нормалей, взвешенных по площади граней.
   - **`_death_star`** – генерирует случайные нормали из комбинаций рёбер, оставляет самые частые.
   - **`_add_supplements`** – добавляет 18 фиксированных направлений (оси, диагонали, углы 45°).
   - Дубликаты удаляются (порог 5°).

3. **Оценка каждой ориентации** (`_evaluate`)
   - **`bottom`** – площадь граней, лежащих на столе (с учётом `FIRST_LAY_H`).
   - **`overhang`** – штраф за нависающие участки (зависит от угла и высоты).
   - **`contour`** – периметр основания (упрощённо: `4*sqrt(bottom)`).

4. **Целевая функция `unprintability`** (`_target_function`)
   - Комбинирует `bottom`, `overhang`, `contour` с весами из словаря `PARAMETER` (или `PARAMETER_VOL` для минимизации объёма поддержек).
   - Формула:  
     `unprintability = TAR_A*(overhang+TAR_B) + RELATIVE_F*(overhang+TAR_C) / (TAR_D + CONTOUR_F*contour + BOTTOM_F*bottom)`

5. **Выбор лучшей ориентации** – кандидат с минимальным `unprintability`.

6. **Построение матрицы поворота** (`_euler`) и применение к модели.

### Использование
```bash
# Стандартный режим (минимизация площади поддержек)
python auto_orient.py input.stl output.stl

# Режим минимизации объёма поддержек
python auto_orient.py input.stl output.stl --volume
